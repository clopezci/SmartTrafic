# Modelo mixto (resumen operativo)

El municipio paga postes, lámparas LED, paneles y gabinete (CapEx de obra, patrimonio suyo).
SmartTrafic entrega en comodato el cerebro, sensores, módem y software, y cobra un canon mensual por cruce.

| Plan | Canon / cruce / mes | Qué desbloquea |
|---|---|---|
| Esencial | $1.000.000 COP | Mesh, noche segura, alertas, tablero |
| Adaptativo | $1.500.000 COP | Colas 100/200/300 m, reportes, bloqueos |
| Premium | $2.100.000 COP | Piso LED, audio, ambulancia, hospital |

Recuperación del kit tecnológico (~$4M COP/cruce) en 6–12 meses. Contrato 24–48 meses por vigencias futuras, no indefinido. Si no se renueva, se retira el cerebro. El acero se queda.

SECOP muestra que municipios chicos ya pagan $50–$400 millones por obra tradicional. El océano azul es OpEx tecnológico, no licitación de $2.000 millones contra Bogotá.
